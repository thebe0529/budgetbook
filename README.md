# BudgetBook

Actual Budget의 빠른 거래 입력·예산 관리 경험을 바탕으로 만드는 가족용 가계부입니다. 독립 제품으로 개발하며, 일부 Actual 코드는 기술 검증 후 재사용 여부를 결정합니다.

## 목표 기능

- 사용자 정의 자산·부채 계정 그룹과 온/오프 버짓
- 분할 거래·이체를 지원하는 행 기반 입력과 월별 예산
- 복식부기 기반 개인 가계용 재무상태표·손익계산서·현금흐름표, 누락 거래 일괄 조정
- 신용카드 할부 청구 예정표와 미래 현금흐름 시뮬레이션
- iPhone 단축어와 은행 거래내역을 받는 REST API
- Pocket ID 로그인, 가족 공유, 최대 30일 오프라인 이용, NAS Docker 배포
- 기본 일일 백업과 선택적 Google Drive 저장

금액 입력칸은 사칙연산과 괄호를 지원하며, Excel 전체 수식 호환은 목표로 하지 않습니다.

[개발계획서](docs/development-plan.md)에 데이터 모델, 개발 단계, 검수 기준과 확정된 운영 정책을 정리했습니다.

## 진행 상태

`/admin/cards/statement`에서 카드별 월별 청구 예정액과 실제 청구서 금액을 비교합니다. 예정일 기준으로 이미 납부한 회차도 포함하고, 수수료·청구 차감 등은 사유와 함께 비교 조정액으로 입력합니다. 조정액은 원장이나 예산에 반영하지 않습니다. 저장한 비교 내역은 당시 회차를 보존하며 이후 납부·취소·환불에 따른 변경 여부를 표시합니다. 청구서 가져오기와 회차별 확인은 후속 작업입니다.

SQLite 기반 복식부기 원장, 카드 할부 예정액·결제 처리, 일괄 조정, 재무상태표·손익계산서·현금흐름 요약 계산을 추가했습니다. 사용자 정의 계좌 그룹, 온/오프 버짓 계좌, 월별 예산 배정과 지출·이월 계산도 포함합니다. `npm test`로 회계 정합성과 영속성을 검증합니다. Pocket ID 관리 화면에서 계좌 생성, 단순 거래와 여러 행의 분할 거래 입력·조회, 소유자 보고서·월별 예산 배정, 가족별 계좌 접근 권한과 수신 거래 승인을 제공합니다. 분할 거래는 버전 확인 후 수정할 수 있고 이전 버전을 기록합니다. 엑셀식 키보드 편집과 전체 장부의 양방향 동기화는 아직 구현되지 않았습니다.

`/app/`은 설치 가능한 PWA 입력 화면의 첫 단계입니다. Pocket ID로 로그인한 뒤 기기 잠금 암호를 만들면 허용된 계좌와 최근 거래 스냅샷, 단순 거래·다중 행 분할 거래·분할 거래 수정 대기열을 IndexedDB에 암호화해 저장합니다. 오프라인은 마지막 온라인 인증 확인 후 최대 30일이며, 재접속 시 대기 거래를 중복 방지 ID와 함께 전송합니다. 분할 거래 수정은 원거래 버전을 검사하고 충돌을 대기열에 남깁니다. 예산 배정·보고서·전체 장부의 완전한 오프라인 동기화는 뒤따릅니다.

`/admin/reports`에서 소유자는 계정별 재무상태표·기간 손익계산서, 현금성 계좌의 기초·입금·출금·기말 잔액과 현금 변동 원거래를 확인할 수 있습니다. 계정명을 누르면 분개별 차변·대변으로 이동합니다. 가족 구성원에게는 허용된 계좌 잔액만 표시합니다.

`/admin/adjustments`에서는 소유자가 누락 거래를 차변·대변 행 여러 개로 한꺼번에 조정할 수 있습니다. 모든 행의 유효성을 확인한 뒤 한 배치로 저장하고, 잘못된 배치는 원래 분개를 보존한 채 별도 역분개로 취소합니다.

`BUDGETBOOK_BACKUP_DIR`을 NAS의 영속 저장 경로로 지정하면 서버 시작 시와 이후 정기적으로 SQLite 온라인 백업을 생성합니다. 기본은 1일 간격, 최근 30개 보관이며 소유자는 `/admin/backups`에서 주기(1~30일)와 보관 개수(1~365개)를 바꾸거나 즉시 백업할 수 있습니다. Google Drive 연동은 아직 없습니다.

`/admin/cards`에서 카드 구매일과 첫 결제 예정일, 할부 개월 수를 입력하고 미결제 예정액을 월별·회차별로 확인할 수 있습니다. 소유자는 카드별 이용 마감일·결제일·결제 월 규칙을 설정할 수 있고, 구매일로 첫 결제 예정일을 미리 확인할 수 있습니다. 첫 예정일을 비우면 규칙에 따라 각 회차를 자동 계산하며 직접 날짜 입력도 지원합니다. 주말은 조정 없음·다음 평일·이전 평일 중 선택할 수 있으며 공휴일은 자동 조정하지 않습니다. 실제 카드 결제일과 출금 계좌를 선택해 지급을 기록합니다. 카드 구매는 구매일의 비용과 예산에 한 번만 반영하며 결제는 카드 부채와 현금 잔액만 바꿉니다. 카드 구매 내역에서 전 회차가 미결제인 구매를 전체 취소할 수 있습니다. 원거래를 보존하고 취소일의 반대 분개와 음수 예산 배분으로 되돌리며 예정액·예측에서 제외합니다. 미결제 구매의 부분취소도 지원하며 균등 배분·앞 또는 뒤 회차부터 차감·회차별 직접 지정을 선택할 수 있습니다. 일부 또는 전 회차를 납부한 구매는 전액·일부 환불을 카드대금 차감으로 기록합니다. 비용·예산을 환불일에 되돌리며 은행 현금 입금은 만들지 않습니다. 실제 계좌 입금은 환불 이력에서 별도로 기록하며 전액·분할 입금을 지원합니다. 이미 기록한 현금성 자산 차변·해당 카드 부채 대변 거래를 환불 이력에 연결할 수 있으며 원장 분개를 추가하지 않습니다. 일부 납부 구매는 미납 예정액을 먼저 줄이고 초과분을 카드대금 차감으로 처리하며, 납부한 회차와 예정일을 보존합니다. 미납 회차에는 균등 배분·앞 또는 뒤 회차부터 차감·회차별 차감액 직접 지정을 지원합니다. 부분취소·환불은 저장 전에 회차별 변경과 계좌 입금 기록 한도를 미리 확인할 수 있습니다.

`/admin/forecast`에서는 소유자가 단건·월별 반복 예정 입출금을 등록·수정·중지하고 카드 미결제액 및 미래 날짜의 확정 거래를 합쳐 현금성 계좌별 예상 잔액을 계산합니다. 예정 회차를 실제 원장 거래와 연결하면 예상액의 중복 집계를 피할 수 있고 연결을 해제할 수도 있습니다. 카드 예정액에 사용할 출금 계좌와 반복 거래별 임시 금액을 바꿔 시뮬레이션할 수 있습니다. 임시 금액은 저장되지 않으며 예정 거래는 확정 원장에 반영되지 않습니다.

금액 입력칸에 연결할 사칙연산 계산 함수도 추가했습니다. 정수 원 단위로 반올림하며 코드 실행 기능은 없습니다. API 키+계정 키로 앱 푸시 원문을 받고, Pocket ID로 로그인하는 정규식 관리 페이지에서 지정한 필드별 규칙으로 파싱해 검토 대기함에 넣습니다. 승인한 내역만 원장에 반영됩니다.
