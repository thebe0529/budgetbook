# BudgetBook

Actual Budget의 빠른 거래 입력·예산 관리 경험을 바탕으로 만드는 가족용 가계부입니다. 독립 제품으로 개발하며, 일부 Actual 코드는 기술 검증 후 재사용 여부를 결정합니다.

## 목표 기능

- 사용자 정의 자산·부채 계정 그룹과 온/오프 버짓
- 분할 거래·이체를 지원하는 행 기반 입력과 월별 예산
- 복식부기 기반 개인 가계용 재무상태표·손익계산서·현금흐름표, 누락 거래 일괄 조정
- 신용카드 할부 청구 예정표와 미래 현금흐름 시뮬레이션
- iPhone 단축어와 은행 거래내역을 받는 REST API
- Pocket ID 로그인, 가족 공유, 최대 30일 오프라인 이용, NAS Docker 배포
- 기본 일일 백업과 선택적 Google Drive 저장

금액 입력칸은 사칙연산과 괄호를 지원하며, Excel 전체 수식 호환은 목표로 하지 않습니다.

## 진행 상태

SQLite 기반 복식부기 원장, 카드 할부 예정액·결제 처리, 일괄 조정, 재무상태표·손익계산서·현금흐름 요약 계산을 추가했습니다. 사용자 정의 계좌 그룹, 온/오프 버짓 계좌, 월별 예산 배정과 지출·이월 계산도 포함합니다. `npm test`로 회계 정합성과 영속성을 검증합니다. Pocket ID 관리 화면에서 계좌 생성, 단순 거래와 여러 행의 분할 거래 입력·조회, 소유자 보고서·월별 예산 배정, 가족별 계좌 접근 권한과 수신 거래 승인을 제공합니다. 분할 거래는 버전 확인 후 수정할 수 있고 이전 버전을 기록합니다. 엑셀식 키보드 편집·로컬 동기화·PWA는 아직 구현되지 않았습니다.

`/admin/cards`에서 카드 구매일과 첫 결제 예정일, 할부 개월 수를 입력하고 미결제 예정액을 월별·회차별로 확인할 수 있습니다. 실제 카드 결제일과 출금 계좌를 선택해 지급을 기록합니다. 카드 구매는 구매일의 비용과 예산에 한 번만 반영하며 결제는 카드 부채와 현금 잔액만 바꿉니다.

`/admin/forecast`에서는 소유자가 단건·월별 반복 예정 입출금을 등록·수정·중지하고 카드 미결제액 및 미래 날짜의 확정 거래를 합쳐 현금성 계좌별 예상 잔액을 계산합니다. 예정 회차를 실제 원장 거래와 연결하면 예상액의 중복 집계를 피할 수 있고 연결을 해제할 수도 있습니다. 카드 예정액에 사용할 출금 계좌와 반복 거래별 임시 금액을 바꿔 시뮬레이션할 수 있습니다. 임시 금액은 저장되지 않으며 예정 거래는 확정 원장에 반영되지 않습니다.

금액 입력칸에 연결할 사칙연산 계산 함수도 추가했습니다. 정수 원 단위로 반올림하며 코드 실행 기능은 없습니다. API 키+계정 키로 앱 푸시 원문을 받고, Pocket ID로 로그인하는 정규식 관리 페이지에서 지정한 필드별 규칙으로 파싱해 검토 대기함에 넣습니다. 승인한 내역만 원장에 반영됩니다.
