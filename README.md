# BudgetBook

Actual Budget의 빠른 거래 입력·예산 관리 경험을 바탕으로 만드는 가족용 가계부입니다. 독립 제품으로 개발하며, 일부 Actual 코드는 기술 검증 후 재사용 여부를 결정합니다.

## 목표 기능

- 사용자 정의 자산·부채 계정 그룹과 온/오프 버짓
- 분할 거래·이체를 지원하는 행 기반 입력과 월별 예산
- 복식부기 기반 개인 가계용 재무상태표·손익계산서·현금흐름표, 누락 거래 일괄 조정
- 신용카드 할부 청구 예정표와 미래 현금흐름 시뮬레이션
- iPhone 단축어와 은행 거래내역을 받는 REST API
- Pocket ID 로그인, 가족 공유, 최대 30일 오프라인 이용, NAS Docker 배포
- 기본 일일 백업과 선택적 Google Drive 저장

금액 입력칸은 사칙연산과 괄호를 지원하며, Excel 전체 수식 호환은 목표로 하지 않습니다.
